# 🍽️ Banquetería Premium - Landing Page Template

Template completo y profesional para un negocio de **banquetería premium / catering de lujo**. Listo para personalizar y usar.

## 📋 Stack Técnico

- **HTML5** semántico
- **Tailwind CSS** (vía CDN)
- **JavaScript nativo** (vanilla JS)
- **Font Awesome** para iconos
- **Google Fonts** (Playfair Display + Inter)
- **Imágenes** vía Unsplash

## 🎨 Diseño

- **Paleta:** Dorados elegantes, crema, marrón oscuro
- **Tipografía:** Playfair Display (títulos) + Inter (cuerpo)
- **Estilo:** Premium, minimalista, sofisticado

## 📁 Estructura

```
banqueteria-01/
├── index.html                 # Página de inicio
├── pages/
│   ├── nosotros.html          # Sobre nosotros
│   ├── servicios.html         # Nuestros servicios
│   ├── galeria.html           # Galería con filtros
│   ├── precios.html           # Planes y precios
│   ├── contacto.html          # Contacto + formulario + mapa
│   ├── privacidad.html        # Política de privacidad
│   └── terminos.html          # Términos y condiciones
├── assets/
│   ├── css/
│   │   └── styles.css         # Estilos personalizados y animaciones
│   └── js/
│       ├── data.js            # Datos mockeados centralizados
│       ├── main.js            # Navbar, animaciones, galería, navbar móvil
│       └── contact.js         # Validación del formulario
```

## 🚀 Cómo usar

1. **Abre `index.html`** en tu navegador para ver el sitio completo.
2. Personaliza los datos en `assets/js/data.js` (nombre del negocio, contacto, etc.).
3. Reemplaza las imágenes de Unsplash con tus propias imágenes.
4. Modifica colores en el `<script>` de Tailwind config dentro de cada HTML.

## ✨ Funcionalidades

- ✅ Navbar sticky con efecto al hacer scroll
- ✅ Menú móvil hamburguesa con animación
- ✅ Animaciones scroll-reveal (Intersection Observer)
- ✅ Contadores numéricos animados
- ✅ Filtros interactivos en la galería
- ✅ Lightbox modal para imágenes
- ✅ Validación de formulario en tiempo real
- ✅ Simulación de envío de formulario
- ✅ Botón flotante de WhatsApp con animación
- ✅ Botón scroll-to-top
- ✅ Diseño responsive (mobile-first)
